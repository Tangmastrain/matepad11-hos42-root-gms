## 三、Magisk 模块

### 新建模块：`debloat_stub3`（v1.2）

空目录 + `.replace` 标记方式 stub 了 5 个 init/persistent 机制拉起、PM 层无法停用的顽固进程宿主 APK（合计 ~500MB）：

| 被移除的 APK                                 | 对应进程                  | 说明                            |
| ---------------------------------------- | --------------------- | ----------------------------- |
| `/system/app/HwNearby/HwNearby.apk`      | —                     | 附近设备                          |
| `/system/priv-app/HiAction/HiAction.apk` | com.huawei.hiaction   | 智能行为                          |
| `/system/system_ext/app/QCC/QCC.apk`     | com.qualcomm.qti.qdma | 高通诊断                          |
| `/system/app/HwAirlink/HwAirlink.apk`    | com.huawei.nearby     | **软总线宿主**（进程名 nearby 的实际代码来源） |
| `/system/app/iConnect/iConnect.apk`      | com.huawei.nearby     | 互联服务（同上）                      |

> 关键经验：Magisk magic mount 不挂载空目录，目录内必须放 `.replace` 文件才会整体替换。

### 禁用的原有模块：`gms12_systemless_dbyw09`

- GMS 整套（MindTheGapps 12.1 子集）以 systemless 方式挂载，禁用后六包全部消失：
  - `com.android.vending`（Play 商店）、`com.google.android.gms`、`com.google.android.gsf`、`com.google.android.partnersetup`、`com.google.android.syncadapters.contacts`、`com.google.android.syncadapters.calendar`
- **恢复方式**：Magisk 管理器重新启用该模块并重启，GMS 完整还原。

### 未动的模块（保留原状）

`playintegrityfix`（无 GMS 后已无作用，无害）、`zn_magisk_compat`、`zygisk_lsposed`、`zygisk_shamiko`、`zygisksu`

## 五、系统级配置修改

### CPU 保底频率脚本：`/data/adb/service.d/z-cpu-minfreq.sh`

- 开机延迟 30 秒生效，governor=schedutil，max 不动（骁龙 865 硬件表顶格）：

| 簇         | 原 min     | 新 min         |
| --------- | --------- | ------------- |
| 小核 cpu0-3 | 300 MHz   | **403.2 MHz** |
| 大核 cpu4-6 | 710.4 MHz | **825.6 MHz** |
| 超大核 cpu7  | 844.8 MHz | **960 MHz**   |

### 其他

- WiFi 曾被 adb 打开（`svc wifi enable`，当时开关处于关闭状态）
- 蓝牙栈重启 + 笔管理服务重启（排查手写笔连接，无配置变更）

## 七、回滚命令速查

```bash
# ── 恢复被卸载的包 ──
adb shell cmd package install-existing <包名>
# 如：com.huawei.search / com.huawei.nearby / com.huawei.contacts / com.huawei.calendar
# 　 com.huawei.localBackup / com.huawei.wallet / com.huawei.wallet.facard
# 　 com.unionpay.tsmservice / com.huawei.hwpanpayservice / com.baidu.input_huawei
# 　 com.huawei.phoneservice
# （A 类 14 项同理：install-existing <包名>）

# ── 恢复被停用的包 ──
adb shell pm enable <包名>
# 如：com.huawei.vassistant com.huawei.hiai com.huawei.recsys com.huawei.hiaction
# 　 com.huawei.hidisk com.huawei.pengine com.huawei.android.thememanager
# 　 com.huawei.ohos.famanager com.huawei.hicard com.huawei.searchservice
# 　 com.huawei.hwdiagnosis com.huawei.hwdetectrepair

# ── 恢复 Magisk stub 的 5 个 APK ──
# Magisk 管理器中禁用或删除 debloat_stub3 模块 → 重启

# ── 恢复 GMS ──
# Magisk 管理器中启用 gms12_systemless_dbyw09 模块 → 重启

# ── 恢复 CPU 频率 ──
adb shell su -c "rm /data/adb/service.d/z-cpu-minfreq.sh; \
 for c in 0 1 2 3; do echo 300000 > /sys/devices/system/cpu/cpu\$c/cpufreq/scaling_min_freq; done; \
 for c in 4 5 6; do echo 710400 > /sys/devices/system/cpu/cpu\$c/cpufreq/scaling_min_freq; done; \
 echo 844800 > /sys/devices/system/cpu/cpu7/cpufreq/scaling_min_freq"

# ── 卸载 VLC ──
adb uninstall org.videolan.vlc
```
