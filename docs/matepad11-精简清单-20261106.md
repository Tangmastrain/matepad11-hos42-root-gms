## 一、通用方法与流程

```bash
# 停用（保留数据，可随时恢复，推荐第一步）
adb shell pm disable-user --user 0 <包名>

# 卸载（对用户 0 生效，系统分区文件仍在，可恢复）
adb shell pm uninstall --user 0 <包名>

# 恢复
adb shell cmd package install-existing <包名>   # 恢复被 uninstall --user 0 的包
adb shell pm enable <包名>                      # 恢复被 disable 的包
```

**操作纪律（务必遵守）：**

1. **先 disable 观察 2~3 天，无异常再 uninstall**。两者效果几乎等同，disable 多一层保险。
2. **每批不超过 5~10 个**，记录批次。出问题用二分法回滚定位。
3. 遇到桌面卡死、开机循环：安全模式（开机时长按电源→长按"关机"）会自动禁用第三方应用，系统应用被禁导致的故障用 `adb shell pm enable <包名>` 恢复；最坏情况 `cmd package install-existing` 逐个恢复。
4. 你的设备已 root：若日后想永久删除（防 OTA 恢复），用 Magisk 模块方式删 `/system` 文件，不要直接 remount 删除系统分区文件。
5. 覆盖层（overlay）、`.apk` 位于 `/system/framework`、`/apex`、带 `provider` 字样的包一律不碰。

**风险等级定义：**
- 🟢 低：纯推广/冗余组件，删除几乎无副作用，随时可恢复
- 🟡 中：有明确副作用（丢某个功能/某些应用受影响），按需删除
- 🔴 高 / 不建议：核心组件、强依赖关系，删除可能卡桌面、开机循环或损坏功能

## 四、推荐精简批次（按此顺序执行）

**第 1 批（零风险，直接删）**：A 类全部 + B 类🟢项 + `mmitest`、`projectmenu`（disable）
**第 2 批（你已明确不用协同/投屏/打印）**：D 类除 `pcassistant` 外整组
**第 3 批（智能助手，按需）**：`vassistant` + `iflytek.speechsuite` + `scanner` + `contentsensor` + `hiaction` + `searchservice` + `ohos.search`（负一屏残留）
**第 4 批（云服务，确认不依赖华为云备份后）**：`hicloud`、`hidisk`、`assetsync`、`assetsyncservice`、`nemo`、`contacts.sync`
**第 5 批（工具二选一）**：笔记二选一、输入法二选一（先切换）、`browser`、`thememanager`、`totemweather`

每批执行后：重启观察桌面、锁屏、通知、WiFi、蓝牙、充电。异常先 `pm enable`，再 `cmd package install-existing`。
